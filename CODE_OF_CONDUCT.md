# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful and constructive
- No harassment, trolling, or personal attacks
- Focus feedback on the work, not the person

## Enforcement

Unacceptable behavior can be reported via the repository's issue tracker or by contacting the maintainer directly. Reports will be reviewed and may result in temporary or permanent bans from the project.

## Scope

This code of conduct applies to all project spaces: issues, pull requests, discussions, and any other project communication channel.
